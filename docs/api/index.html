RecipeShare API (1.0.0)

Download OpenAPI specification:

License: UNLICENSED

레시피 작성·공유·탐색 서비스 백엔드 API. backend/src/routes/*.ts를 분석해 작성한 명세로, 실제 컨트롤러의 Zod 검증 스키마·에러 응답 포맷과 1:1로 대응한다.

인증

POST /api/auth/register 또는 POST /api/auth/login 응답의 token을 Authorization: Bearer <token> 헤더로 보호된 엔드포인트에 사용한다.

공통 에러 포맷

모든 에러는 { "error": string, "details"?: object } 형태다. Zod 검증 실패는 error: "Validation failed" + details에 ZodError.flatten() 결과가 담긴다.
